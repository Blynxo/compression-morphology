Topics

Key terms

Pixel
One tiny dot of a picture. A 10 \times 10 image has 10 rows and 10 columns, so 10 \times 10 = 100 pixels.
Grey level (intensity)
How bright a pixel is. In a normal 8-bit image 0 is black and 255 is white.
Bit and byte
A bit is the smallest piece of storage: a 0 or a 1. A byte is 8 bits.
n-bit image
Every pixel is stored with n bits, so it can have 2^n different grey levels. An 8-bit image allows 2^8 = 256 levels; a 5-bit image allows 2^5 = 32.
Symbol
One value we need to write down, for example one grey level such as a_2.
Frequency and probability
Frequency n_k is how many times a symbol appears. Probability is the frequency divided by the total number of pixels, p_k = n_k / N. It is a number between 0 and 1, and all probabilities add up to 1: \sum_k p_k = 1.
Code and codeword
The string of bits we write instead of the symbol, for example 011.
Compression
Storing the same picture with fewer bits. Lossless: decoding gives back exactly the original. Lossy: some information is thrown away for ever.
Binary image
An image with only two values: object (white, 255) and background (black, 0).
